# Number Axioms

## Real Numbers

### Field Axioms

1. **Closure under addition**: For all real numbers \(a\) and \(b\), \(a + b\) is a real number.
2. **Commutativity of addition**: For all real numbers \(a\) and \(b\), \(a + b = b + a\).
3. **Associativity of addition**: For all real numbers \(a\), \(b\), and \(c\), \((a + b) + c = a + (b + c)\).
4. **Additive identity**: There exists a real number \(0\) such that for all real numbers \(a\), \(a + 0 = a\).
5. **Additive inverse**: For every real number \(a\), there exists a real number \(-a\) such that \(a + (-a) = 0\).
6. **Closure under multiplication**: For all real numbers \(a\) and \(b\), \(ab\) is a real number.
7. **Commutativity of multiplication**: For all real numbers \(a\) and \(b\), \(ab = ba\).
8. **Associativity of multiplication**: For all real numbers \(a\), \(b\), and \(c\), \((ab)c = a(bc)\).
9. **Multiplicative identity**: There exists a real number \(1\) such that for all real numbers \(a\), \(a \cdot 1 = a\).
10. **Multiplicative inverse**: For every real number \(a\), if \(a \neq 0\), there exists a real number \(a^{-1}\) such that \(a \cdot a^{-1} = 1\).
11. **Distributive property**: For all real numbers \(a\), \(b\), and \(c\), \(a(b + c) = ab + ac\).
12. **Trichotomy**: For every real number \(a\), exactly one of the following holds: \(a > 0\), \(a = 0\), or \(a < 0\).
13. **Transitivity of inequality**: For all real numbers \(a\), \(b\), and \(c\), if \(a < b\) and \(b < c\), then \(a < c\).
14. **Addition of inequalities**: For all real numbers \(a\), \(b\), and \(c\), if \(a < b\), then \(a + c < b + c\).
15. **Multiplication of inequalities**: For all real numbers \(a\), \(b\), and \(c\), if \(a < b\) and \(c > 0\), then \(ac < bc\).
16. **Order of reciprocals**: For all real numbers \(a\) and \(b\), if \(a > 0\) and \(b > 0\), then \(1/a < 1/b\).
17. **Archimedean property**: For every real number \(a\), there exists a positive integer \(n\) such that \(a < n\).
18. **Density of real numbers**: For all real numbers \(a\) and \(b\) such that \(a < b\), there exists a rational number \(r\) such that \(a < r < b\).
19. **Completeness property**: Every nonempty set of real numbers that is bounded above has a least upper bound.
20. **Least upper bound property**: If \(S\) is a nonempty set of real numbers that is bounded above, then \(S\) has a least upper bound.
21. **Existence of square roots**: For every real number \(a\) such that \(a \geq 0\), there exists a real number \(b\) such that \(b^2 = a\).
22. **Existence of nth roots**: For every real number \(a\) and positive integer \(n\), if \(a \geq 0\), then there exists a real number \(b\) such that \(b^n = a\).
23. **Existence of absolute value**: For every real number \(a\), there exists a real number \(|a|\) such that \(|a| \geq 0\) and \(|a| = a\) if \(a \geq 0\) and \(|a| = -a\) if \(a < 0\).
24. **Triangle inequality**: For all real numbers \(a\) and \(b\), \(|a + b| \leq |a| + |b|\).
25. **Existence of additive inverses**: For every real number \(a\), there exists a real number \(-a\) such that \(a + (-a) = 0\).
26. **Existence of multiplicative inverses**: For every real number \(a\), if \(a \neq 0\), there exists a real number \(a^{-1}\) such that \(a \cdot a^{-1} = 1\).
27. **Existence of additive identity**: There exists a real number \(0\) such that for all real numbers \(a\), \(a + 0 = a\).
28. **Existence of multiplicative identity**: There exists a real number \(1\) such that for all real numbers \(a\), \(a \cdot 1 = a\).


### Order Axioms

1. **Trichotomy**: For every real number \(a\), exactly one of the following holds: \(a > 0\), \(a = 0\), or \(a < 0\).
2. **Transitivity of inequality**: For all real numbers \(a\), \(b\), and \(c\), if \(a < b\) and \(b < c\), then \(a < c\).
3. **Addition of inequalities**: For all real numbers \(a\), \(b\), and \(c\), if \(a < b\), then \(a + c < b + c\).
4. **Multiplication of inequalities**: For all real numbers \(a\), \(b\), and \(c\), if \(a < b\) and \(c > 0\), then \(ac < bc\).
5. **Order of reciprocals**: For all real numbers \(a\) and \(b\), if \(a > 0\) and \(b > 0\), then \(1/a < 1/b\).
6. **Archimedean property**: For every real number \(a\), there exists a positive integer \(n\) such that \(a < n\).
7. **Density of real numbers**: For all real numbers \(a\) and \(b\) such that \(a < b\), there exists a rational number \(r\) such that \(a < r < b\).
8. **Completeness property**: Every nonempty set of real numbers that is bounded above has a least upper bound.
9. **Least upper bound property**: If \(S\) is a nonempty set of real numbers that is bounded above, then \(S\) has a least upper bound.

## Positive Integers

### Axioms

1. **Well-Ordering Principle**: Every nonempty set of positive integers has a least element.
2. **Peano Axioms**: 
    1. 1 is a positive integer.
    2. For every positive integer \(n\), \(n + 1\) is a positive integer.
    3. There is no positive integer \(n\) such that \(n + 1 = 1\).
    4. For all positive integers \(m\) and \(n\), if \(m + 1 = n + 1\), then \(m = n\).
    5. If \(A\) is a set of positive integers such that 1 is in \(A\) and for every positive integer \(n\), if \(n\) is in \(A\), then \(n + 1\) is in \(A\), then \(A\) contains every positive integer.
 3. **Induction Axiom**: If \(A\) is a set of positive integers such that 1 is in \(A\) and for every positive integer \(n\), if \(n\) is in \(A\), then \(n + 1\) is in \(A\), then \(A\) contains every positive integer.
 4. **Division Algorithm**: For every positive integer \(a\) and positive integer \(b\), there exist unique integers \(q\) and \(r\) such that \(a = bq + r\) and \(0 \leq r < b\).
 5. **Fundamental Theorem of Arithmetic**: Every positive integer greater than 1 can be written as a product of prime numbers, and this factorization is unique up to the order of the factors.
 6. **Euclidean Algorithm**: For every positive integer \(a\) and positive integer \(b\), there exists a unique positive integer \(d\) such that \(d\) is the greatest common divisor of \(a\) and \(b\), and there exist integers \(x\) and \(y\) such that \(d = ax + by\).
 7. **Bezout's Identity**: For every positive integer \(a\) and positive integer \(b\), there exist integers \(x\) and \(y\) such that \(ax + by = \gcd(a, b)\).
 8. **Extended Euclidean Algorithm**: For every positive integer \(a\) and positive integer \(b\), there exist integers \(x\) and \(y\) such that \(ax + by = \gcd(a, b)\).
 9. **Chinese Remainder Theorem**: For every positive integer \(n_1\), positive integer \(n_2\), integer \(a_1\), and integer \(a_2\), there exists an integer \(x\) such that \(x \equiv a_1 \pmod{n_1}\) and \(x \equiv a_2 \pmod{n_2}\).
 10. **Fermat's Little Theorem**: For every prime number \(p\) and integer \(a\), if \(p\) does not divide \(a\), then \(a^{p-1} \equiv 1 \pmod{p}\).
 11. **Euler's Theorem**: For every positive integer \(n\) and integer \(a\), if \(n\) and \(a\) are relatively prime, then \(a^{\phi(n)} \equiv 1 \pmod{n}\).
 12. **Wilson's Theorem**: For every prime number \(p\), \((p - 1)! \equiv -1 \pmod{p}\).
 13. **Quadratic Reciprocity**: For every odd prime number \(p\) and odd prime number \(q\), if \(p\) and \(q\) are relatively prime, then \(\left(\frac{p}{q}\right)\left(\frac{q}{p}\right) = (-1)^{\frac{p-1}{2}\frac{q-1}{2}}\).
 14. **Goldbach's Conjecture**: Every even integer greater than 2 can be written as the sum of two prime numbers.
 15. **Riemann Hypothesis**: The nontrivial zeros of the Riemann zeta function have real part equal to 1/2.
 16. **Collatz Conjecture**: For every positive integer \(n\), the sequence defined by \(a_0 = n\) and \(a_{i+1} = \begin{cases} a_i/2 & \text{if } a_i \text{ is even} \\ 3a_i + 1 & \text{if } a_i \text{ is odd} \end{cases}\) eventually reaches 1.
 17. **Twin Prime Conjecture**: There are infinitely many pairs of prime numbers that differ by 2.
 18. **Goldbach's Weak Conjecture**: Every odd integer greater than 5 can be written as the sum of three prime numbers.
 19. **Perfect Number Conjecture**: There are infinitely many perfect numbers.
 20. **Catalan's Conjecture**: The only solution in the positive integers of the equation \(x^a - y^b = 1\) is \(x = 3\), \(a = 2\), \(y = 2\), and \(b = 3\).
 21. **Rational Root Theorem**: If a polynomial with integer coefficients has a rational root, then the root is of the form \(p/q\) where \(p\) divides the constant term and \(q\) divides the leading coefficient.
 22. **Fundamental Theorem of Algebra**: Every nonconstant polynomial with complex coefficients has at least one complex root.
 23. **Intermediate Value Theorem**: If \(f\) is a continuous function on the interval \([a, b]\) and \(y\) is a number between \(f(a)\) and \(f(b)\), then there exists a number \(c\) in \((a, b)\) such that \(f(c) = y\).
 24. **Mean Value Theorem**: If \(f\) is a continuous function on the interval \([a, b]\) and differentiable on the interval \((a, b)\), then there exists a number \(c\) in \((a, b)\) such that \(f'(c) = \frac{f(b) - f(a)}{b - a}\).
 25. **Cauchy's Mean Value Theorem**: If \(f\) and \(g\) are continuous functions on the interval \([a, b]\) and differentiable on the interval \((a, b)\), then there exists a number \(c\) in \((a, b)\) such that \(\frac{f'(c)}{g'(c)} = \frac{f(b) - f(a)}{g(b) - g(a)}\).
 26. **L'Hôpital's Rule**: If \(\lim_{x \to a} f(x) = \lim_{x \to a} g(x) = 0\) or \(\lim_{x \to a} f(x) = \lim_{x \to a} g(x) = \pm \infty\) and \(\lim_{x \to a} \frac{f'(x)}{g'(x)}\) exists, then \(\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}\).
 27. **Taylor's Theorem**: If \(f\) is a function that is \(n + 1\) times differentiable on an interval containing \(a\) and \(f^{(n+1)}\) is continuous on the interval, then for every \(x\) in the interval, there exists a number \(c\) between \(a\) and \(x\) such that \(f(x) = f(a) + f'(a)(x - a) + \frac{f''(a)}{2!}(x - a)^2 + \cdots + \frac{f^{(n)}(a)}{n!}(x - a)^n + \frac{f^{(n+1)}(c)}{(n+1)!}(x - a)^{n+1}\).
 28. **Euler's Formula**: For every real number \(x\), \(e^{ix} = \cos(x) + i\sin(x)\).
 29. **Euler's Identity**: \(e^{i\pi} + 1 = 0\).
 30. **Pythagorean Theorem**: For every right triangle with legs of length \(a\) and \(b\) and hypotenuse of length \(c\), \(a^2 + b^2 = c^2\).
 31. **Law of Sines**: For every triangle with angles \(A\), \(B\), and \(C\) and sides of length \(a\), \(b\), and \(c\), \(\frac{\sin(A)}{a} = \frac{\sin(B)}{b} = \frac{\sin(C)}{c}\).
 32. **Law of Cosines**: For every triangle with angles \(A\), \(B\), and \(C\) and sides of length \(a\), \(b\), and \(c\), \(c^2 = a^2 + b^2 - 2ab\cos(C)\).
 33. **Law of Tangents**: For every triangle with angles \(A\), \(B\), and \(C\) and sides of length \(a\), \(b\), and \(c\), \(\frac{a - b}{a + b} = \frac{\tan\left(\frac{A - B}{2}\right)}{\tan\left(\frac{A + B}{2}\right)}\).
