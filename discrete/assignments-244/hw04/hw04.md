This suggests a recurrence relation of the form:

$\begin{cases} P(n) = n \times P(n-1) & \text{if } n > 0 \\ P(0) = 1 & \text{if } n = 0 \end{cases}$

```rust
fn count_bit_strings(n: u32) -> u32 {
    if n == 0 {
        // Base case: There is 1 bit string of length 0, which is an empty string
        return 1; 
    } else {
        return 2 * count_bit_strings(n - 1);

}
```

## Question 7

> Solve $a_n = 5a_{n−1} − 6_a{n−2}$ for $n \geq 2$, $a_0 = 1$, $a_1 = 0$.

Given the recurrence relation $a_n = 5a_{n-1} - 6a_{n-2}$, we can solve it using the characteristic equation method.

The characteristic equation is $r^2 = 5r - 6$, which simplifies to $r^2 - 5r + 6 = 0$.

Factoring the quadratic equation, we get $(r - 2)(r - 3) = 0$.

Therefore, the roots are $r_1 = 2$ and $r_2 = 3$.

The general solution is $a_n = c_1(2^n) + c_2(3^n)$.

Using the initial conditions $a_0 = 1$ and $a_1 = 0$:

$a_0 = c_1(2^0) + c_2(3^0) = c_1 + c_2 = 1$

$a_1 = c_1(2^1) + c_2(3^1) = 2c_1 + 3c_2 = 0$

Solving the system of equations:

$c_1 + c_2 = 1$

$2c_1 + 3c_2 = 0$

$c_1 = 3$

$c_2 = -2$

Therefore, the solution to the recurrence relation is $a_n = 3(2^n) - 2(3^n)$.

> For integer multiplication, we solved the n-bit problem by using three solutions of n/2-bit  problems and additional cn operations. However, the analysis was very complicated. If we use a  simpler analysis and solve the n-bit problem by using four solutions of n/2-bit problems and  additional $c_1n$ operations, then what will be the recurrence? What will be the solution to that  recurrence achieved from the simpler analysis?





If we solve an n-bit integer multiplication problem using four subproblems of size $\frac{n}{2}$ and additional c₁n operations, the recurrence relation becomes:

$T(n) = 4T(n/2) + c_1n$

This is a general form of the Master Theorem, where $a = 4$, $b = 2$, and $f(n) = c_1n$, where $a$ represents the number of subproblems, $b$ represents the factor by which the problem size is reduced, and $f(n)$ represents the cost of dividing the problem and combining the solutions.


The solution to this recurrence relation is:

$T(n) = \Theta(n^{\log_b a}) = \Theta(n^{\log_2 4}) = \Theta(n^2)$

Therefore, the time complexity of this simpler analysis is $\Theta(n^2)$.

This simpler analysis indicates that using four subproblems instead of three still results in a time complexity of $\Theta(n^2)$ for integer multiplication.

The dominating term in the time complexity is the recursion depth.
