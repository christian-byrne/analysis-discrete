> Let $P(n)$ be the statement that $1^3 + 2^3 + \ldots + n^3 = (\frac{n(n + 1)}{2})^2$ for the positive integer n.

#### a) What is the statement P(1)?

$P(1)$ is the statement that $1^3 = (\frac{1(1 + 1)}{2})^2$.


#### b) Show that P(1) is true, completing the basis step of the proof.


$1^3 = 1 = (\frac{1(1 + 1)}{2})^2 = (\frac{2}{2})^2 = 1^2 = 1$.


#### c) What is the inductive hypothesis?

The inductive hypothesis is that $1^3 + 2^3 + \ldots + k^3 = (\frac{k(k + 1)}{2})^2$ for some positive integer $k$.


#### d) What do you need to prove in the inductive step?

In the inductive step, we need to prove that $1^3 + 2^3 + \ldots + k^3 + (k + 1)^3 = (\frac{(k + 1)(k + 2)}{2})^2$.

#### e) Complete the inductive step, identifying where you use the inductive hypothesis.

Assume the inductive hypothesis: $1^3 + 2^3 + \ldots + k^3 = (\frac{k(k + 1)}{2})^2$. 

Then we need to show:

$1^3 + 2^3 + \ldots + k^3 + (k + 1)^3 = (\frac{k(k + 1)}{2})^2 + (k + 1)^3$

$= \frac{k^2(k + 1)^2}{4} + (k + 1)^3$

$= \frac{k^2(k + 1)^2 + 4(k + 1)^3}{4}$

$= \frac{(k + 1)^2(k^2 + 4(k + 1))}{4}$

$= \frac{(k + 1)^2(k^2 + 4k + 4)}{4}$

$= \frac{(k + 1)^2(k + 2)^2}{4}$

$= (\frac{(k + 1)(k + 2)}{2})^2$.

Thus, $1^3 + 2^3 + \ldots + k^3 + (k + 1)^3 = (\frac{(k + 1)(k + 2)}{2})^2$.

This completes the inductive step and proves the statement by mathematical induction.

Theorem: Any amount of money n≥4 can be formed using two-dollar and five-dollar bills.

**Base Cases**:

- $P(4)$: 4 = 2 + 2
- $P(5)$: 5 = 5

**Inductive Hypothesis**: Assume that $P(k)$ is true for some positive integer $k$ where $k \geq 5$. That is, $k = 2a + 5b$ for some nonnegative integers $a$ and $b$.


**Inductive Step**: We need to prove that $P(k + 1)$ is true. 


- Case 1: If $k$ is even, then $k + 1 = 2(a + 1) + 5b$. Since $a + 1$ is a nonnegative integer, $P(k + 1)$ is true.
- Case 2: If $k$ is odd, then $k + 1 = 2(a - 2) + 5(b + 2)$. Since $a - 2$ and $b + 2$ are nonnegative integers, $P(k + 1)$ is true.

In both cases, $P(k + 1)$ is true. Therefore, by the principle of strong induction, $P(n)$ is true for all positive integers $n \geq 4$ $\blacksquare$.

> Prove that the first player has a winning strategy for the game of Chomp, introduced in a lecture
at the class, if the initial board is square. [Hint: Use strong induction to show that this strategy
works. For the first move, the first player chomps all cookies except those in the left and top
edges. On subsequent moves, after the second player has chomped cookies on either the top or
left edge, the first player chomps cookies in the same relative positions on the left or top edge,
respectively.]


Let $P(n)$ be the statement that the first player has a winning strategy for the game of Chomp if the initial board is an $n \times n$ square. We will prove that $P(n)$ is true for all positive integers $n$.




**Base Case**: $P(1)$ is the statement that the first player has a winning strategy for the game of Chomp if the initial board is a 1x1 square. This is true because the first player can chomp the only cookie on the board.




**Inductive Hypothesis**: Assume that $P(1), P(2), \ldots, P(k)$ are true for some positive integer $k$. That is, the first player has a winning strategy for the game of Chomp if the initial board is an $n \times n$ square. 


Then, the first player chomps all cookies except those in the left and top edges. On subsequent moves, after the second player has chomped cookies on either the top or left edge, the first player chomps cookies in the same relative positions on the left or top edge, respectively. Thus, $P(k + 1)$ is true.


Therefore, by the principle of strong induction, $P(n)$ is true for all positive integers $n$ $\blacksquare$.
