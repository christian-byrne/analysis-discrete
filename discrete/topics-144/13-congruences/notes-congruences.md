## Hashing Functions

- A **hashing function** is a function that maps a large amount of data to a smaller data set. Hashing functions are used in computer science to quickly search for data in large databases.
- A hashing function *h* assigns memory location *h(k)* to a record that has key *k*
- Many different hashing functions can be used to map a key to a memory location. The goal is to distribute the keys evenly among the memory locations.
  - One of the most common: *h(k) = k mod m* where *m* is the number of memory locations.
- A hashing function should be onto, meaning that every memory location is possible, which is satisfied by the function *h(k) = k mod m*.
- Because a hashing function is not one-to-one, it is possible for two keys to map to the same memory location. This is called a **collision**.
  - One way to solve is to assign the first free memory location to the key that maps to the same location as another key

## Psuedo-Random Numbers

- A **pseudo-random number generator** is a function that generates a sequence of numbers that appear to be random but are actually deterministic.


### Linear Congruential Generators

- Choose four integers:
  - *m* - the modulus
  - *a* - the multiplier
  - *c* - the increment
  - *x*<sub>0</sub> - the seed
- The sequence of pseudo-random numbers is generated by the formula:
  - *x*<sub>*n*</sub> = (*a* * *x*<sub>*n*-1</sub> + *c*) mod *m*
- The sequence of pseudo-random numbers will repeat after *m* numbers have been generated.
- The first *m* numbers generated are called the **period** of the generator.
  - After the period, the sequence will repeat.
- Unfortunately, it has been shown that sequences of pseudorandom numbers generated in this way do not share some important properties of "truly" random sequences.
  - Therefore, linear congruential generators are not suitable for cryptographic applications or large scale simulations.
    - For these purposes, some sort of algorithm or sample numbers arising from a physical process are used.

**Pure Multiplicative Generators**:
- *c* = 0
- For example, the sequence of pseudo-random numbers generated by the formula:
  - *x*<sub>*n*</sub> = (*a* * *x*<sub>*n*-1</sub>) mod *m*, where *m* = 2<sup>*31*</sup> - 1 and *a* = 7<sup>5</sup> = 16807 is a popular choice.


### Testing Randomness

- The **Chi-Square Test** is a statistical test that can be used to determine if a sequence of numbers is random.
  - The test is based on the fact that if a sequence of numbers is random, then the number of times each number appears in the sequence should be approximately the same.
  - The test is used to determine if the difference between the observed number of times a number appears and the expected number of times a number appears is statistically significant.
- The **Kolmogorov-Smirnov Test** is another statistical test that can be used to determine if a sequence of numbers is random.
  - The test is based on the fact that if a sequence of numbers is random, then the cumulative distribution function of the sequence should be approximately uniform.
  - The test is used to determine if the difference between the observed cumulative distribution function and the expected cumulative distribution function is statistically significant.
- The **Serial Test** is a statistical test that can be used to determine if a sequence of numbers is random.
  - The test is based on the fact that if a sequence of numbers is random, then the number of times each pair of numbers appears in the sequence should be approximately the same.
  - The test is used to determine if the difference between the observed number of times a pair of numbers appears and the expected number of times a pair of numbers appears is statistically significant.

### Check Digits

- A **check digit** is a digit that is added to a number to make it easier to detect errors.
- The check digit is calculated by applying a function to the number.
- Parity check bits:
  - A **parity check bit** is a bit that is added to a binary number to make it easier to detect errors.
  - A bit string representing digital information is split into blocks of a fixed size.
  - A parity check bit is appended to each block.
  - When the information is transmitted, the parity check bits are used to detect errors.
  - If a string contains a parity check bit that is incorrect, we can conclude that an error has occurred.
    - However, if the string contains a parity check bit that is correct, we can't necessarily conclude that no error has occurred
  - A parity check bit can detect an odd number of errors, but not an even number of errors.
- Check bits computed using congruences are used extensively to verify the correctness of various kinds of identification numbers, such as credit card numbers, ISBNs, and UPCs.
